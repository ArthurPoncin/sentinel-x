Câblage du Raspberry Pi

Raspberry Pi 4 Model B. Le « 2018 » imprimé sur la carte est l'année de son dessin : tous les Pi 4 le portent. Ce qui se branche sur chaque port, puis le moteur pas à pas de la caméra sur le connecteur GPIO.

  • Portsalim, écran, webcam, ESP32, Ethernet
  • GPIOmoteur pas à pas sur les broches 4, 31, 33, 35, 37, 39
  • Wi-Firéservé au point d'accès de la table
5V alimentation 5 V 3V3 alimentation 3,3 V GND masse commande du moteur (GPIO) Les broches entourées sont celles qu'on utilise. Toutes les autres restent libres.

Ce qui se branche sur les ports

Vu de dessus, connecteur GPIO en haut. Les ports USB sont interchangeables : la webcam et l'ESP32 marchent sur n'importe lequel. L'écran va sur le micro-HDMI 1, celui à côté de la prise jack.

Le connecteur GPIO et le moteur pas à pas

Colonne de gauche : les broches impaires, côté intérieur de la carte. Colonne de droite : les paires, le long du bord. Le moteur tire environ 200 mA, sans à-coups : la broche 5 V du Pi suffit.

Wi-Fi

Ne connecte pas le Pi à un autre Wi-Fi

Le Pi n'a qu'une puce Wi-Fi. Elle sert de point d'accès SentinelX-<table> à l'ESP32 et au PC Opérateur.

  • Connecté au Wi-Fi du labo, le point d'accès s'éteint : plus de mesures, plus de sirène.
  • Pour Internet, branche le câble Ethernet : le Wi-Fi reste le point d'accès.
  • Pour le remettre : sudo nmcli connection up sentinel-x-ap
Avant d'allumer

Quatre vérifications

  1. Pi éteint pendant que tu câbles le connecteur GPIO.
  2. Le − de la carte sur la broche 39, le + sur la broche 4. Inversés, la carte ou le Pi peuvent griller.
  3. Rien sur les broches 1 et 17 (3V3), et aucun fil entre un 5V et une GPIO.
  4. La caméra tournée à la main pour regarder droit devant : le moteur ne sait pas où il est, il compte ses pas depuis là.
Mise en route

Sur le Pi, une fois

  1. git pull
  2. infra/stepper.sh : retire le servo s'il y en avait un, déclare le moteur.
  3. infra/plug-and-play.sh <table> --no-flash : le récapitulatif affiche Moteur ✓ moteur pas à pas.
  4. docker compose logs vision | grep Stepper doit dire ready. Les LED de la carte clignotent quand la caméra tourne.
